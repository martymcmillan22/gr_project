# Semantic Catalogs

Canonical assets in this directory:
- `macro_map.json`: official industry-sector ontology and source of truth
- `macroeconomic_map.csv`: flattened export derived from the ontology
- `semantic_operating_stack.json`: deterministic Phase-31 contract for RR visuals, VA guidance, SOP/workflow architecture, and publishing structures

Workflow metadata points here so downstream tooling can discover the semantic catalog location without relying on repo-root files.
