# Narrative Creator Workflow
Document ID: BTPE-CREATOR-001
Version: v1.0
Status: Active

---

## Overview

The Narrative Creator Workflow is the first non-validator BTPE workflow.
It consumes a validated Strict Mode QPU and transforms it into deterministic
narrative output.

## Purpose

The workflow produces:

- a four-beat story arc
- a structured outline
- scene cards
- a rendered narrative string

## Engine Output

The engine returns a structured object containing:

- source workflow metadata
- source QPU
- story beats
- outline
- scenes
- narrative
- semantic block
- BTPE propagation layer

## Status

Creator Workflow is active and registered in the workflow ecosystem.
