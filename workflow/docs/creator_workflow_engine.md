# Creator Workflow Engine
Document ID: BTPE-CREATOR-ENGINE-001
Version: v1.0
Status: Active

---

The Creator Workflow engine executes the definition in a fixed order:

1. seed the narrative context
2. derive four beats
3. expand to outline sections
4. render scenes and narrative output

The engine validates the final structure against the Creator Workflow schema
and propagates semantic metadata into BTPE layers.
