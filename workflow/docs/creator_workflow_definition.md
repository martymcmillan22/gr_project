# Creator Workflow Definition
Document ID: BTPE-CREATOR-DEF-001
Version: v1.0
Status: Active

---

This workflow definition declares a four-node deterministic narrative pipeline:

- `creator_seed_node`
- `creator_arc_node`
- `creator_outline_node`
- `creator_render_node`

The workflow consumes a validated QPU, expands it into a narrative arc, and
emits a structured output suitable for BTPE Studio and downstream creative
systems.
