# Feature Expansion Overview

## What Expansion Is

Feature expansion is deterministic proposal generation for missing workflow coverage, new semantic capabilities, and cross-feature integrations.

## How Proposals Are Generated

Expansion proposals are generated by:

- workflow/feature_expansion.py

The engine analyzes:

- registry coverage gaps
- semantic gaps (intents, MLAS tiers, BTIF classes, tags)
- opportunities for multi-feature bundles
- opportunities for cross-feature integrations

## Governance

Expansion governance is defined in:

- workflow/meta/governance_long_term.json

Apply mode requires explicit approvals:

- expansion_approval
- semantic_approval
- structural_approval
- sync_approval

## CLI Commands

- python3 workflow/cli.py expand
- python3 workflow/cli.py expand-all
- python3 workflow/cli.py expand-preview

Apply examples:

- python3 workflow/cli.py expand-all --apply --approve-expansion --approve-semantic --approve-structural --approve-sync
- python3 workflow/cli.py expand --target workflow-expansion-hub --apply --approve-expansion --approve-semantic --approve-structural --approve-sync

Preview example:

- python3 workflow/cli.py expand-preview --write

## AI Surfaces

- workflow/ai_prompts/ai_expansion_prompt.txt
- workflow/meta/ai_expansion.json

## Proposal Schema

Each proposal includes:

- category
- proposed_feature
- rationale
- confidence
- governance_requirements
- semantic_lineage
- dependency_graph_impact

## Example Proposal Types

- new_feature: fill missing semantic coverage
- new_semantic_intent: add absent intent class
- new_mlas_btif_pattern: add BTIF/MLAS expansion pattern
- new_tag_ontology_entry: normalize or extend tags
- multi_feature_bundle: coordinated feature bundle proposal
- cross_feature_integration: integration orchestrator proposal
