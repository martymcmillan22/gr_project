# Project Middle Layer v1.0.0

Tag: v1.0.0-project-middle-layer

Project Middle Layer is now complete and available as the semantic operating substrate for GrassRoots.

This release delivers a deterministic semantic system that spans compile, identity-aware branching, lineage, governance, orchestration, and platform interoperability. Operators now have a unified control plane with capability-gated actions and auditable workflows across admin, API, and command surfaces.

The platformization layer is fully in place, including plugins, extensions, marketplace assets, BTIF+ export and validation, external agents, federation, and gateway integration. Recent UX upgrades improve daily operations with persistent admin state restore, density controls, trend sparklines, and one-click demo data seeding.

Project Middle Layer is designed to scale safely: deterministic by default, governed by explicit permissions, and extensible through controlled interfaces.

## Highlights

- Semantic compile and deterministic project generation
- Identity and branch-path specialization with lifecycle snapshots
- Lineage, drift, stability, alerts, and semantic recommendations
- Governance and controls: roles, permissions, versioning, merge, audit
- Operational orchestration: pipelines, schedules, webhooks, sync, replication
- Platformization: marketplace, plugins, extensions, gateway, federation, BTIF+, external agents
- Operator UX improvements for faster and safer command-surface workflows
