# North Star Compiler Layer — Execution Binding

## Compiler Identity
- MLAS Tier: Semantic Utility
- BTPE Category: Execution Pattern Engine
- Identity Rail: AM Identity
- Semantic Clock Position: AM‑04
- Semantic Role: North Star Compiler

## Compiler Function
The Compiler Layer activates the AutoFill Module and binds its outputs to the North Star fields.

## Compiler Rules
- Rule 01 — AutoFill Module must execute before any manual edits.
- Rule 02 — AutoFill outputs must populate all empty fields.
- Rule 03 — AutoFill must not overwrite manually declared values.
- Rule 04 — AutoFill must refuse execution if MLAS, BTPE, or Identity Rail are missing.
- Rule 05 — AutoFill must validate Semantic Clock Position before binding.
- Rule 06 — AutoFill must enforce Penpot → MDX → React → MLAS → BTPE → Identity Rail.

- No inference allowed.
