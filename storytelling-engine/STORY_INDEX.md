## **How to Use This Index**

### **For Status Tracking**
- Check the Status column to see what's done
- Update Last Updated date when you work on an entry
- Move entries from "Pending" → "In Progress" → "Complete"

### **For Navigation**
- Click entry link to jump to full story in MASTER_DOCUMENT.md
- Each link has an anchor (#entry-N) for direct access
- Use browser find (Cmd+F) to search by title

### **For Planning**
- Priority column helps you decide what to work on next
- "Next Action" tells you exactly where to start
- High-priority entries are marked for immediate expansion

## **Expansion Workflow**

### **To Expand a Placeholder Entry:**

1. **Pick an entry** from the Pending list (suggest starting with High priority)
2. **Open MASTER_DOCUMENT.md** → Scroll to the entry
3. **Fill in sections** (in this order):
   - Talking Points (3–5 hooks)
   - Core Concept (single sentence + themes)
   - Synopsis (200–300 words)
4. **Expand to full entry** with remaining 10 sections
5. **Update STORY_INDEX.md:**
   - Change Status from ⏳ to 🔄 (In Progress)
   - Update Last Updated date
   - Fill Core Concept column
   - Update Next Action
6. **Mark Complete** when all 13 sections are done (change to ✅)
