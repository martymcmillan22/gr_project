# ✅ **ENGINE CHECKLIST — Quality Control & Verification**

**Version:** 1.0  
**Purpose:** Ensure every story meets Story-Telling Engine standards  
**How to Use:** Print this, track completed items, archive for reference

---

## **Story-Telling Engine v1.0 — The 6 Core Parts**

Every story must satisfy all 6 parts of ENGINE_SCHEMA.md before being marked **Complete** in STORY_INDEX.md:

1. **PART 1 — Core Philosophy** — Story aligns with engine's creative principles
2. **PART 2 — Standard Entry Structure** — All 13 sections present & filled
3. **PART 3 — Quality Standards** — Consistency, clarity, pacing, coherence
4. **PART 4 — Dynamic Navigation Rules** — Internal & external links correct
5. **PART 5 — Versioning & Archival** — Version tagged & archived properly
6. **PART 6 — Chapter Level Architecture** — Format chosen + chapter count + pacing rules applied

---

# **CHECKLIST 1 — COMPLETION VERIFICATION**

Use this checklist **before marking an entry as "Complete"** in STORY_INDEX.md.

## **Structural Completeness**

- [ ] Title is final and locked
- [ ] All 13 required sections present
- [ ] No placeholder text remains (all *[Pending]* tags removed)
- [ ] Entry is properly anchored in MASTER_DOCUMENT.md

## **Talking Points Quality**

- [ ] Exactly 3–5 bullet points
- [ ] Each point ≤ 15 words
- [ ] Points answer "Why read this?"
- [ ] Tone is compelling without hyperbole
- [ ] No spoilers in talking points

## **Core Concept Quality**

- [ ] Single sentence describes premise
- [ ] 2–3 thematic pillars identified
- [ ] Unique element clearly stated
- [ ] Total length ≤ 50 words
- [ ] No major plot reveals

## **Synopsis Quality**

- [ ] Length: 200–300 words
- [ ] Structure: Beginning → Middle → End (narrative flow)
- [ ] Tone matches story's intended mood
- [ ] Present tense used consistently
- [ ] No major twist/surprise spoiled
- [ ] First sentence hooks reader
- [ ] Stakes are clear
- [ ] Genre/tone is evident

## **Chapter Structure Quality**

- [ ] Chapter count: 36–60 total (not under, not over)
- [ ] Each chapter has: Number + Title + 1-line description
- [ ] Chapter titles are evocative (not generic)
- [ ] Descriptions are 20–30 words each
- [ ] Natural Act divisions marked
- [ ] Pacing varies (no two chapters identical length)
- [ ] Scene flow is logical (Chapter X → Chapter X+1 makes sense)
- [ ] No orphaned chapters (all belong to clear structure)

## **Dynamic Navigation Quality**

- [ ] Internal DN provided (within-story links)
- [ ] External DN provided (cross-story connections, if applicable)
- [ ] All DN links use proper markdown format: `[Text](link)`
- [ ] Explanations clarify why connection matters
- [ ] No broken links (all destinations exist or are noted as TBD)
- [ ] DN doesn't spoil connected stories

## **Soundtrack Timeline Quality**

- [ ] Minimum 8 key moments covered
- [ ] Each entry: Chapter/Scene + Song + Artist + Mood
- [ ] Mood descriptions are evocative (1 line each)
- [ ] Optional: Spotify/Apple Music links included
- [ ] Music selections support, not dominate, narrative
- [ ] Variety of genres/tempos/artists
- [ ] Original compositions clearly marked as such

## **Character Profiles Quality**

- [ ] Main characters: 5–10 profiles (full depth)
- [ ] Secondary characters: 10–15 profiles (medium depth)
- [ ] Each profile includes:
  - [ ] Role (Protagonist/Antagonist/etc.)
  - [ ] Age at story start
  - [ ] Physical appearance (2–3 sentences)
  - [ ] Personality (3–4 traits with examples)
  - [ ] Motivation (what they want, why)
  - [ ] Arc (how they change by end)
  - [ ] Backstory (1–2 sentences)
  - [ ] Key relationships (to other characters)
- [ ] No character has duplicate name within universe
- [ ] Each main character is distinct (no cookie-cutter personalities)
- [ ] Character motivations are believable
- [ ] Character arcs are visible/earned

## **Research File Quality**

- [ ] All sources properly cited
- [ ] Each source includes: Title + Author + How Used + Verification
- [ ] Verification status marked (✅ Checked / ⚠️ Partial / 🔍 Pending)
- [ ] Historical facts are accurate (spot-check 3–5 claims)
- [ ] Speculation is clearly labeled as such
- [ ] Sources are credible (not Wikipedia alone for facts)
- [ ] No unsourced claims presented as fact

## **Future Timeline Quality**

- [ ] Planned sequels/spin-offs identified (if any)
- [ ] Each includes: Title + Timeline + Concept + Connection
- [ ] Connection to current story is clear
- [ ] Intentions are marked as "Planned" vs. "Exploratory"
- [ ] Timeline is realistic (not vague "someday")
- [ ] Vision aligns with story's ending

## **Table of Contents Quality**

- [ ] Chapter list complete (all chapters from Section 5 present)
- [ ] Format consistent (same style for all chapters)
- [ ] Page numbers or estimated lengths provided
- [ ] Part/Act headings hierarchical
- [ ] Total TOC length ≤ 3 pages
- [ ] Optional mood tags are consistent

## **Bibliography Quality**

- [ ] Citation format chosen and applied consistently (APA/MLA/Chicago)
- [ ] All sources cited in Research File appear in Bibliography
- [ ] Each citation includes: Author + Title + Publication + Date
- [ ] URLs included where applicable
- [ ] Sections properly labeled (Sources Cited / Inspirational / Recommended / Academic)
- [ ] No orphaned sources (all cited somewhere in story)
- [ ] Alphabetical ordering (if using that convention)

## **Anti-Plagiarism Section Quality**

- [ ] Original Concept Statement provided (1–2 paragraphs)
- [ ] 5–7 Unique Elements identified and explained
- [ ] Comparison to Similar Works includes: Similar + Diverges
- [ ] Originality Certification provided (author statement)
- [ ] Tone is professional and defensible
- [ ] No claims that cannot be backed up

# **CHECKLIST 2 — CONSISTENCY AUDIT**

Use this checklist **across multiple entries** to ensure universe consistency.

## **Naming Consistency**

- [ ] All character names are unique within universe (scan all entries for duplicates)
- [ ] Location names spelled consistently (if mentioned in multiple stories)
- [ ] Terminology consistent (if "The Rift" in Story A, not "The Great Divide" in Story B)
- [ ] Title formatting consistent (format: "Main Title" or "Main (Subtitle)" across all)

## **Tone & Voice Consistency**

- [ ] Each story has distinct, recognizable voice
- [ ] Voice remains consistent within each story
- [ ] No abrupt tonal shifts within a single story
- [ ] Narrative POV clearly established (and consistent)
- [ ] Genre tone matches intent

## **Technical Consistency**

- [ ] All markdown headers use proper hierarchy
- [ ] Link formatting consistent: `[Text](link)` everywhere
- [ ] Emphasis consistent: Use *italic* or **bold** the same way
- [ ] No orphaned sections (all sections belong to clear parent)
- [ ] Section numbering consistent across all entries
- [ ] File naming consistent (MASTER_DOCUMENT.md / STORY_INDEX.md / etc.)

## **Content Consistency**

- [ ] Character descriptions don't contradict between entries (if shared universe)
- [ ] Timeline is internally consistent (Event A happens before Event B)
- [ ] World-building rules consistent (magic systems, sci-fi mechanics, etc.)
- [ ] Thematic resonance intentional (not accidental repetition)

---

# **CHECKLIST 3 — DYNAMIC NAVIGATION COMPLIANCE**

Use this checklist to verify DN completeness.

## **Internal DN (Within-Story Links)**

- [ ] Related chapters are cross-linked
- [ ] Thematic mirrors identified (Chapter X ↔ Chapter Y)
- [ ] Plot callbacks flagged in DN
- [ ] Foreshadowing highlighted
- [ ] Minimum 5 internal DN links per story

## **External DN (Cross-Story Connections)**

- [ ] If story shares universe with others, DN provided
- [ ] If story has character cameos, DN points to source
- [ ] If story is sequel/prequel, DN establishes timeline
- [ ] Format: `See also: [Story Title](MASTER_DOCUMENT.md#entry-N)`
- [ ] Explanation of connection provided (1–2 sentences)

## **DN Testing**

- [ ] All DN links can be followed (test by hand or with link checker)
- [ ] No broken links to nonexistent entries
- [ ] Links use correct anchor format (#entry-1, #entry-2, etc.)
- [ ] DN doesn't accidentally spoil other stories

---

# **CHECKLIST 4 — CHARACTER CONTINUITY**

Use this when character appears in multiple stories.

- [ ] Character name spelled identically
- [ ] Age advances appropriately between timelines
- [ ] Personality remains recognizable (evolution okay, contradiction is not)
- [ ] Backstory doesn't contradict previous story's version
- [ ] Relationships with other shared characters are consistent
- [ ] If character is cameo, appearance is brief/natural (not forced)

---

# **CHECKLIST 5 — RESEARCH ACCURACY**

Use this to spot-check claims.

- [ ] Spot-check 3–5 factual claims: Verify against source
- [ ] Historical dates are correct (within 1-year margin of error acceptable for fiction)
- [ ] Scientific concepts accurately represented (or clearly labeled as speculative)
- [ ] Place names and geography correct (if real-world locations)
- [ ] Cultural details respectfully researched (not stereotyped)
- [ ] All citations point to actual, published works (not made-up sources)

---

# **CHECKLIST 6 — EXPANSION READINESS**

Use this when moving a Placeholder → In Progress → Complete.

## **Before Starting**

- [ ] Read full ENGINE_SCHEMA.md once
- [ ] Review one Completed entry as stylistic reference
- [ ] Open MASTER_DOCUMENT.md to target entry
- [ ] Have STORY_INDEX.md open for status updates

## **During Expansion**

- [ ] Fill Sections 1–4 first (Talking Points, Title, Core Concept, Synopsis)
- [ ] Expand to Chapters (Section 5) — aim for 36–60
- [ ] Add DN (Section 6) linking related chapters
- [ ] Add Soundtrack (Section 7) for 8+ key moments
- [ ] Profile Characters (Section 8) — 5–10 main, 10–15 secondary
- [ ] Document Research (Section 9) — verify all claims
- [ ] Outline Future (Section 10) — sequel/spin-off vision
- [ ] Create TOC (Section 11) — chapter list
- [ ] Compile Bibliography (Section 12) — all sources
- [ ] Write Anti-Plagiarism (Section 13) — originality statement

## **Before Completion**

- [ ] Run Checklist 1 (Completion Verification) — all items checked
- [ ] Run Checklist 2 (Consistency Audit) — no contradictions
- [ ] Run Checklist 3 (DN Compliance) — internal + external links complete
- [ ] Update STORY_INDEX.md: Status → ✅ Complete, Last Updated → today
- [ ] Archive previous version (if revision)
- [ ] Add entry to MASTER_DOCUMENT.md Changelog
